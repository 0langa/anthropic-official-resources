# Tokenomics on AWS: Control and optimize your Claude spend

The price per token is only part of what you pay to run Claude on AWS. The rest depends on how you set it up. Your default models, your admin controls, and the way your agents are built all shape the final bill. You control every one of them, and this session shows you how to optimize the cost of Claude on AWS.

In this technical session, Anthropic and AWS will walk through two before-and-after cost comparisons. The first covers admin setup, spend controls, and default model settings for Claude Code, Claude Enterprise, and Claude Desktop on Amazon Bedrock. The second shows builders on the Claude API how to measure cost per completed task for an existing agent, then use Claude Code to find savings and measure again.
