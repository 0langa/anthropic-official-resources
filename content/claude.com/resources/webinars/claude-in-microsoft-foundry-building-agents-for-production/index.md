# Claude in Microsoft Foundry: Building agents for production

Claude models are now generally available in Microsoft Foundry. This session focuses on building for production.

If you are a developer or architect who is past the experimentation stage and ready to move your Claude-powered agent into production on Azure, this webinar is for you. With Claude now generally available in Microsoft Foundry, teams can access Claude models through their existing Microsoft relationship, with billing, authentication, and commitment retirement all handled through Azure. We'll walk through how to deploy Claude models in Microsoft Foundry, connect them to real business workflows, and apply the governance and observability controls that production systems require.
