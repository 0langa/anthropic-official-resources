## What you’ll learn

- Understand what drives your bill: tokens used and the model doing the work.
- Track and report: the analytics dashboard, Analytics Chat, letting members see their own spend, the spend report CSV export, the Analytics API for usage and cost data, and the Compliance API for audit logs.
- Control: spend limits at the org, group and member level, threshold alerts for admins and members, model defaults and model access, and the Admin API for setting member limits at scale.
- Prove the value: the Claude Code Value tab (beta) in the analytics dashboard, and a simple operating loop to run each quarter: set defaults, monitor, share results back, adjust.
