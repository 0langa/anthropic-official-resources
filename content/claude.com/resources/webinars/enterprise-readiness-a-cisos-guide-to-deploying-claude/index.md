# Enterprise Readiness: A CISO's Guide to Deploying Claude

The best security teams don't block AI. They lead the rollout, with full visibility into who uses it, what data it touches, and what agents can do.

Anthropic's Dor Fledel and Belinda Neal will walk through what a successful enterprise rollout looks like, whether you're standing up Claude Enterprise for the first time or expanding from chat into Claude Code and agentic workflows.

We’ll cover choosing between direct and cloud-provider deployment, the controls that apply (including what's new), how to secure agentic work on a user's machine, and why the strongest rollouts start with your innovators.

## What you’ll learn

- How to choose a deployment model. The trade-offs between using Claude directly from Anthropic and using it through your cloud provider, and how each affects data handling, identity, and which controls you own.
- The control families that matter, and what's new. Identity and access, data governance, audit logging, and admin policy in Claude Enterprise, plus how the security tools you already run can plug in.
- How successful rollouts scale. Why the strongest programs run a scoped beta with internal early adopters, and how to move from chat to Claude Code without losing visibility.
