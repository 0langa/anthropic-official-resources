# The State of Cybersecurity: What Frontier AI Changes for Security Leaders

A briefing for CISOs and security leaders on what attackers can do with AI now, and how to adjust your security program to keep up.

Attackers now use AI to find and exploit software vulnerabilities, and security teams are under pressure to find and fix them sooner. That changes how security programs set priorities and measure their teams. In this session, speakers from Anthropic walk through what our published threat research shows about how attackers use AI, and what security leaders are changing in their programs as a result. You’ll also see how teams use Claude Security to scan their codebases and review suggested patches, so you can start fixing vulnerabilities right away.
