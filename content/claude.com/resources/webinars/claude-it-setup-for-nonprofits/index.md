# Claude IT Setup for Nonprofits

A working session for the person who administers Claude at your nonprofit, whether that's an IT lead, Security, or the staffer who ended up with the admin login. We'll walk the full setup path in the order it should happen: sign-in and identity, data settings, features, launch, and bringing existing accounts into your organization. We'll show exactly where each control lives in the admin console. You'll leave with a checklist of every step, so your organization goes from "provisioned" to "configured and in use".
