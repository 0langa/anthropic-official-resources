# Scaling development with remote agents: Best practices and deep dive with Augment Code

Join Augment Code and Anthropic for an exclusive technical deep dive into how remote agents are transforming software development. Learn how to evolve from individual contributor to supervisor of AI engineering teams, managing dozens of agents running in the cloud. This workshop goes beyond theory to show actual implementation, prompts, and infrastructure powering end-to-end task completion. Discover how Claude 4 enables unprecedented agent reliability and see live demonstrations of the new developer experience where you supervise rather than code directly.
