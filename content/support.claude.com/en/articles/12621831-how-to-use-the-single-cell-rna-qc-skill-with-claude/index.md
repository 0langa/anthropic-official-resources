## What is the single-cell-rna-qc skill?[](https://academy.claude.com/tutorials/how-to-use-the-single-cell-rna-qc-skill-with-claude)

The single-cell-rna-qc skill gives Claude the ability to perform quality control on single-cell RNA-seq data using scverse best practices with MAD-based filtering and comprehensive visualizations for .h5ad and .h5 files.

## Who should use the single-cell-rna-qc skill?[](https://academy.claude.com/tutorials/how-to-use-the-single-cell-rna-qc-skill-with-claude)

This skill is designed for bioinformaticians, computational biologists, single-cell genomics researchers, and data scientists working with single-cell RNA-seq data who need to quickly assess data quality, identify and filter low-quality cells, and generate standard QC visualizations without writing code from scratch.

## How to access the skill in Claude Code[](https://academy.claude.com/tutorials/how-to-use-the-single-cell-rna-qc-skill-with-claude)

1. Download the [ZIP file for the single-cell-rna-qc skill(opens in new tab)](https://github.com/anthropics/life-sciences/releases/download/v1.0.0/single-cell-rna-qc-v1.0.0.zip)
2. On your own computer, unzip it into a new folder named `single-cell-rna-qc` inside `~/.claude/skills/`, so that the skill's `SKILL.md` file is at `~/.claude/skills/single-cell-rna-qc/SKILL.md`
3. Start Claude Code and run `/skills` to check that **single-cell-rna-qc** is listed

Learn about [where Claude Code loads skills from(opens in new tab)](https://code.claude.com/docs/en/skills).

## How to access the skill in [Claude.ai(opens in new tab)](http://claude.ai/)[](https://academy.claude.com/tutorials/how-to-use-the-single-cell-rna-qc-skill-with-claude)

**For Organization Owners (Team and Enterprise)**

1. Download the ZIP for the single-cell-rna-qc skill [here(opens in new tab)](https://github.com/anthropics/life-sciences/releases/download/v1.0.0/single-cell-rna-qc-v1.0.0.zip)
2. Open [Organization settings(opens in new tab)](https://claude.ai/admin-settings), search for “Skills” and click the first result. Make sure the switches for skills and code execution are both turned on.
3. Open [your organization’s skills and plugins(opens in new tab)](https://claude.ai/admin-settings/skills), select the add button at the top, and upload the skill zip file

[Learn about turning on skills for your team(opens in new tab)](https://support.claude.com/en/articles/13119606-provisioning-and-managing-skills-for-your-organization)

**For Individual Claude Users**

1. Download the ZIP file for the single-cell-rna-qc skill [here(opens in new tab)](https://github.com/anthropics/life-sciences/releases/download/v1.0.0/single-cell-rna-qc-v1.0.0.zip)
2. Open [skills in Claude(opens in new tab)](https://claude.ai/customize/skills) and select **Add**. If you don’t see skills or **Add**, search Settings for “Code execution” and make sure it’s on (on a Team or Enterprise plan, contact your team admin).
3. Choose the upload option, then select the skill zip file
