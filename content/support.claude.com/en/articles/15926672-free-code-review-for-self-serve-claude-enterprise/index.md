# Free Code Review for self-serve Claude Enterprise

We're offering eligible self-serve Claude Enterprise organizations three months of free Code Review. The free period covers Code Review runs on repositories hosted at github.com only (not CLI-based code review), capped at 1500 reviews per organization per week. An admin must opt in to start the free period, and Code Review automatically continues as a paid feature at standard pricing when the free period ends.

This article explains who's eligible, how to enroll, and what happens when the free period ends.

## Eligibility

The offer is available to self-serve Claude Enterprise organizations, both new and existing, that haven’t run Code Review in the 30 days before the offer launches. Having Code Review enabled doesn’t affect eligibility on its own.

The offer isn't available to:

- Claude Enterprise organizations that have run Code Review in the 30 days before the offer launches.

- Sales-assisted Claude Enterprise organizations.

- Claude Team, Pro, Max, and Free plans.

Your organization's subscription must be active and in good standing when you opt in and throughout the free period. If your organization moves to a sales-assisted Claude Enterprise account after opting in, you keep the offer for the remainder of your free period.

## How to enroll

An admin opts in from the Code Review setup page. Opting in starts your organization's free period immediately. There's nothing for individual users to claim.

Organizations that don't see setup-page prompt aren't eligible for this offer.

## How the offer works

Once your organization opts in:

- Code Review runs are free for three months from the opt-in date.

- Free usage is capped at 1500 Code Review runs per organization per week. Reviews beyond the weekly cap are billed at standard pricing.

- Free runs don't appear as a line item on your invoice.

What's not covered: self-hosted Code Review (the GitHub Action), Code Review on GitHub Enterprise Server or a github.com data-residency instance (.ghe.com), Claude Code usage, Claude Cowork, Claude chat, the API, or any usage outside Code Review. That usage continues to be metered and billed as normal.

## What happens when the free period ends

When your free period ends, Code Review continues as a paid feature and runs are billed at standard pricing. We send a reminder email to admins seven days before the free period ends.

An admin can disable Code Review at any time, including during the free period, from the Code Review settings page. Disabling it before the free period ends means there's no paid charge.

## Enrollment window

The enrollment window opens August 12, 2026 and closes on September 11, 2026 11:59 PM Pacific Time. Anthropic may shorten or extend the window at its discretion.

Organizations that opt in during the window receive the full three-month free period, even if the enrollment window has closed by the time the free period ends.

## Track usage in your organization

Admins can see Code Review usage, including free promotional runs, on the Code Review analytics page in organization settings.

## Temporary holds on eligibility

If we detect abuse, we may pause an organization's free period or remove the offer while we review the activity.

## Frequently asked questions

### Do we need to do anything to claim it?

Yes. An admin must opt in from the Code Review setup page. The free period starts when you opt in.

### What is considered a run?

A run is one Code Review of a pull request. Each of these counts as one run against your weekly free allowance:

- Opening a new pull request

- Pushing new commits to an open pull request

- Requesting a re-review of the same commits

A run of Code Review can be triggered either via @claude review or automatically depending on your org settings.

### Is there a usage cap?

Yes. Free runs are capped at 1500 Code Review runs per organization per week. Runs beyond the cap are billed at standard pricing.

### Does this cover the self-hosted GitHub Action?

No. Only Code Review runs are covered. Self-hosted Code Review and all other Claude usage continue to be billed as normal.

### Does this cover GitHub Enterprise Server or .ghe.com instances?

No. Only Code Review on repositories hosted at github.com is covered. If your organization connected a GitHub Enterprise Server or a .ghe.com data-residency instance, Code Review on those repositories continues to be billed as normal.

### What happens at the end of the free period?

Code Review continues as a paid feature at standard pricing. We'll show the first-charge date when you opt in and send a reminder seven days before. An admin can disable Code Review at any time to avoid charges.
