Correction

At 0:40, 1:20, and 3:35, the video says `allowed-tools` restricts which tools Claude can use. It doesn't. It pre-approves the tools you list, so Claude can use them without asking until you send your next message. Claude can still use other tools, under your normal permission settings. To take tools away while a skill is active, use `disallowed-tools`. See [Pre-approve tools for a skill(opens in new tab)](https://code.claude.com/docs/en/skills).
